## 2. 训练工程（D2 显存实录——16GB 共享卡上的 14B QLoRA DPO）

| 尝试 | 配置 | 结果 |
|---|---|---|
| 1 | ml 2048（SFT 线平移） | OOM：进程 12.60GiB 差 98MiB（bnb 反向去量化 × 最长对 1613 tok 边界激活） |
| 2 | +optim adamw_bnb_8bit + ml 1664 | 同点位 OOM（优化器状态首 step 才物化，救不了首 backward 峰） |
| 3 | +torch_empty_cache_steps + ml 1616 | 同点位 OOM（清理只在 optimizer step 间生效） |
| 截断探针 | ml 1400 丢弃式 | L1613→11.50GB allocated（seq 伸缩实测 ~2.7MB/tok），证 cap 路径可行 |
| 定稿 | **cap1350 数据 + ml1360 + optim8bit + empty_cache** | s3 全绿 3/3 步；峰值 12.39GiB（预算 12.64） |

随判三条（lessons 入账）：
- **DPO 显存 ≠ SFT 显存平移**：micro-batch = chosen+rejected 拼批 [2,L]，同一 12300 需求线
  下天然 +46% 激活；playbook"ref_adapters 显存不翻倍（16GB 可行）"的姊妹域实验仓先例是
  ≤1024 tok 语料，F1 域 1100-1725 tok 不平移。
- **第三方上卡进程是硬变量**：第三方进程 610MiB / 390MiB / 258MiB 三个不同进程在 40 分钟内
  轮流上卡，把 ~0.25GB 余量逐次吃穿（s9 两次死于 6/9 步与等待门）。NEED 线从 12300
  提至 12900（= 仅常驻服务口径）+ 等待-重试循环（幂等条件修正为"末步 ckpt 存在"，
  失败残留目录曾被误判为完成）。
- **优化器 8bit 的生效时机**：adamw_bnb_8bit 状态在首个 optimizer.step 物化——它改善
  稳态（s9 后期）但不救首个 backward 峰；报告口径勿混用。

训练读数（s3 logging，R8 相关）：
- **起点 logps 已大幅分离**：chosen -19.57 vs rejected -55.45（R8 预注册"chosen 起点已
  高概率"实证；偏好对的收益在负侧打压）。
- 步 1/2 loss=0.6931（=ln2，warmup 期 lr 0→2.5e-6 rewards 尚为 0），步 3 loss 0.6321、
  rewards/accuracies 0.9375、margins 0.127——**信号在第 3 步才咬合**（与"3 步压满行为轴"
  的 C-1 剂量学一致）。

## 4. 判决

### R7（守门 ∧ 主轴）——**成立**

- 守门（预注册数值化）：三臂全过——F1 带内（s1 持平；s3/s9 +1.2 < 2 分带）、格式 100%、
  幻觉 0 不回现。
- 主轴（校准块定向：提升空间在证据质量与无病边界侧）：证据质量 = val-reg F1 +1.2（s3/s9，
  带内微增）+ ood 覆盖 +0.5（0.969→0.974）；无病边界 = 逐位持平（neg 19/20 的 1 miss
  为 MED-B 已知的 5% 微扰边界，非 DPO 作用面）。**test-rob 满分不误读为无空间——空间
  在质量侧被兑现了小额读数**。
- 剂量形态：1 步无效 / 3 步咬合饱和 / 9 步零过校正——与 C-1（48 对×3 步压满行为轴）和
  本波训练动力学（rewards 第 3 步才非零）三方一致。

### R8（负侧消退率 + 出口词形态）——**成立，读法定格为"负侧已满、收益在正侧"**

- 起点分离实证：chosen logps -19.57 vs rejected -55.45（s3 logging 步 1）——预注册的
  "chosen 起点已高概率"在本域成立，偏好对的可教空间本就在负侧打压。
- 负侧消退读数：基线负侧已压满（出口违约 0、rejected 低条目形态与冠军产出中位 5 项相距
  甚远），DPO 三臂负侧零回潮（出口 0/0、条目数噪声级波动、garbled/minimal 全保持——
  H 批"缺省带过校正"未复现）。
- 边际收益定位：正侧证据质量（F1/cov 微增）——**"DPO 教的是结构完整性"在本域的实证形态
  = 条目内证据原子覆盖增强，而非条目数上移**（X4 附观察的精化）。
