## 1. 口径（v1 → v1.1 修正记录，开发期由 gold 门与人核回路定案）

五轴按 HANDOFF §2.2 件一细则实现，三处修正（评测器 docstring 同步）：

1. **②中文分号检查收窄到 diseases 块内**：gold 依据散文含合法中文分号（val-reg×1 / test-rob×2，
   均不在块内），system prompt 规则 2 只约束疾病列表；散文中文分号记 info 不判败。
2. **⑤原子单位词表限检验/体征值**（%|℃|mmHg|拉丁单位|次/分|cm 类）：年龄/时长不计——gold 标注
   含标注者补充的产史/时长数值（rec-0751/0340/0772 共 5 原子），输入不可追溯；安全意图（X5）
   本就是防编造检验值。年龄感知在场：token=N岁 且输入含 `年龄：N` 算在场。
3. **v1.1 再剔除 `个` 与裸 `次`**：轴③人核校准发现 "1个月"→"1个"、"5～6次"→"6次" 假原子
   （症状史计数非检验值）；心率类 `次/分` 保留。

轴适用面：test-rob 上 ①③⑤ = N/A（gold 是基材原图疾病/依据，对乱码与极简输入无判分意义）。
gold 门：三集五轴全满分（v1 与 v1.1 各过一次；v1.1 有原子条目 val-reg 55/80、test-ood 47/60）。

推理形态：`swift infer --temperature 0 --max_new_tokens 768`；0.6B/1.7B/8B/14B =
`qwen3 --enable_thinking false`，4B = `qwen3_nothinking`（槽位差异见 §5 caveat）。8B/14B 为
bnb 4bit 口径（16GB 卡 bf16 放不下）；14B batch=1 + `expandable_segments` 贴边通过
（batch=4 于 52/80 处 OOM，实录在 matrix-run.log）。

## 3. R1 判决（按 PLAN §4 预注册原文逐条对照）

| # | 预注册预期（原文） | 读数 | 判决 |
|---|---|---|---|
| 1 | 14B 零样本 seen-F1 不低（教科书病先验强） | 0.412，五档最高且显著非零，但量级仅为"部分先验"（<0.5，P 0.38/R 0.49 均偏） | **部分中**：方向中（容量阶梯+非零底），"先验强"量级不中 |

**校准块**（只改 MED-C/D 设计层，R1 判决层冻结）：
- **MED-B**：主判据 val-reg 疾病 F1 的基线锚 = 0.412@14B（4bit 口径），提升空间大；格式护栏
  （≥95%）与依据覆盖护栏（≥0.937）零样本已满足——护栏条款从"教学目标"降为"防回退监测"。
- **MED-C**：对症轴预期从"翻正"改为"保持 + 小档提升"（大档已过，翻正无空间）；重心移
  **"无病"条件**（X2，本卡范围外的已知缺口——底座对健康病历的零样本行为未测，MED-C 立项
  时先零样本探针再决定造数）。反向校验条款不变（其余轴零漂移）。
- **MED-D**：⑤幻觉零样本低位（14B 仅 2 原子）→"数值防编造"不是 DPO 高收益轴；4B 离群说明
  该轴档位敏感，DPO 守门轴维持但预期收益下调。

## 5. 错误分析副产品（MED-C 审计先行原料）

**三类典型失败形态**：
1. **症状当诊断**（①主力失败，全档）：输出"上腹痛/腹胀/贫血/右前臂损伤"级症状或体征标签，
   而非疾病名（例 0.6B rec-0901/0297，8B rec-0829"急性皮肤感染;发热" vs gold 丹毒）。
2. **规则复读**（②/④，小档）：`<diseases>无;</diseases>` 块 + 逐字回声规则句"判断患者身体
   健康的原因。"，无分条序号（例 0.6B val-reg ② 失败 5 条中 4 条此形态）。
3. **类别误判**（④minimal）：极简条件输入下答"无/数据异常"而非"推测疾病 或 缺少关键诊断
   信息"（例 0.6B rec-0758/0616/0425）；4B+ 基本消失。

**新增第四形态（④⑤交叉，4B 离群）**：**参考值内插**——编造教科书正常参考值当检验结果
（rec-1074：输入 Hb 70g/L → 输出"140g/L"，另 100fl/31pg/36% 全为正常值量级；test-ood 侧
145mmol/L/200μg/L 同型）。已抽验非误判（输入确无这些数值）。4B 槽位为 Instruct-2507 变体
（不同训练谱系 + qwen3_nothinking 模板），离群归因含档位与谱系双重因素，不拆分。

**SYNONYMS 首批回填**（2 条，近失误分析：42 对候选中仅此 2 对为"肝硬变/肝硬化"级命名变体，
其余全为粒度/亚型差不入表——F1 差距主因是知识粒度，规范化缺失贡献极小）：
- `慢性阻塞性肺病 → 慢性阻塞性肺疾病`（样例 0.6b val-reg rec-0183）
- `类风湿性关节炎 → 类风湿关节炎`（样例 0.6b val-reg rec-0340）
（边界条`腰椎间盘突出/症`按保守纪律暂缓。）变更已记 PLAN 变更记录。

**③人核校准**（10 条分层抽样：8B val-reg 高/低覆盖各 5）：低覆盖端 2 条假漏（"1个月"型假
原子→v1.1 已修；皮疹/红疹关键词同义差→已知噪声保留）；高覆盖端 5 条全真（rec-0142 九个
检验值原子全数复现）。代理方向正确，噪声双侧 <10%。

**MED-B 设计层发现（对拍前置件四产出）**：F1 全 1154 行 token 长度 **1096~1725**（14B
tokenizer 实测）——skill/playbook 原"本仓序列 <1K token"注记错误，`--max_length 1024` 会
**全量截断**；MED-B 必用 **max_length 2048**。`check_template_med.py` 对拍 14B/1.7B 双档
全绿（`qwen3 + enable_thinking=False` + `default+ignore_empty_think`，文本逐字 + 掩码边界
双相等；qwen3_nothinking 在本仓数据形态下不等——空 think 前缀侧差异，d1 结论在本仓复现）。

## 6. caveat 与遗留

- 8B/14B 读数为 bnb 4bit 口径（14B 另有 batch=1 + expandable_segments 贴边）——与 MED-B
  bf16+QLoRA 训练后的评测口径不完全同侧，基线锚引用时注明；MED-B 收官时可选补 bf16 评测列。
- 4B 槽位是 Qwen3-4B-**Instruct-2507**（家族中该档唯一在位形态），与同族 hybrid-thinking 档
  谱系不同，跨档比较含此混杂。
- "无病"条件（system prompt 规则 4）不在 test-rob（MED-0 决策 X2 延后）——底座该轴零样本
  行为未测，MED-C 立项第一动作补零样本探针。
- 推理 response 均带空 `<think>\n\n</think>\n\n` 前缀（qwen3 关思考模板的生成前缀侧行为，
  playbook §2 已知项；判分前剥离，评测器已处理）。
