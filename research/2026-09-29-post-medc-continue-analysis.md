# MED-C 后战略复核：是否继续微调、哪些实验值得做、剩余收益预期

> 2026-09-29 · 状态：分析 + 建议（D-08 决策输入）。背景：MED-C 收官（R5' 终判不过，
> 交付配方维持 f1 冠军），剩 MED-D（DPO）/MED-E（OOD 收官）两波排队。本文回答三问：
> ①要不要继续微调 ②还有哪些实验值得做 ③预期收益还剩多少。
> 方法：信号残量 × 杠杆未测面 × 交付物完成度 三账合算（预注册与红线对齐，不发明新口径）。

## 2. 杠杆×失败轴完成度

四杠杆族（容量/数据/偏好/脚手架）：容量✓ 数据✓ **偏好=空白格** 脚手架=零散（模板对拍
属工程件，无读数格）。**跳过 MED-D = 交付的地图 v1 自带空格**，与立项目标（杠杆×失败轴
地图，README 一句话）不符。MED-E 是地图的组装件，不可跳。

## 3. 各实验收益预期（量化到分）

### 3.1 MED-D DPO（~1 晚，GPU ~2.5h）——建议按卡执行

- **主轴预期**：val-reg F1 0.800 → +0~4 分，守门带 0.780-0.820 内守住为底线。理由：
  champion 残余失败 = 知识粒度差（42 对近失误 40 对粒度差），X4 实证 chosen 优势形态 =
  条目粒度+证据类型递进——偏好对恰含粒度教学信号；但剂量小（1/3/9 步开关型），预期为
  边际修正非档位跃迁。
- **R8 负侧**：幻觉已 0，标的转为概括/无递进依据形态的消退率（定性）+ 出口形态纪律的
  正用验证（DPO 对比损失恰是压坏出口的机制——若出口漂移形态在负侧被压，MED-C 教训
  完成正反闭环）。
- **信息保底（双向枚举）**：步数全 0 增量 → "score 信号全路径不值钱"定案（强于 R4 的
  "SFT 路径不值钱"），偏好格读"本语料下无增量"入地图——**负结果也是地图读数**。
  P(任一轴正读数)≈40-50% · P(信息产出)=100%。

### 3.2 MED-E 收官（~1 晚含增件）——必做（交付件）

- R9 量化 + 泛化存在性判决（unseen 覆盖 0.969/0.985 > 零样本 0.937，正读数待正式落卷）
- 全配方列（零样本/f1/f2/f3c/cg/cm/cn/cn-low/DPO 终态）+ 长尾分层 + **bf16 消口径列**
- 产出 = 地图 v1（四列补齐：读数/代价轴/适用域/归属层）——项目的兑现件。

### 3.3 新识别的零成本实验（建议并入等待窗）

- **离线重判：unseen"命名/证据"分叉**（零 GPU，~30min）：cn-low 上 unseen 覆盖 0.985
  vs F1 0.067 的分叉是全项目最有信息量的未读读数——检查已落输出：**依据文本是否已说出
  正确病名而 diseases 块没列出**？是 → unseen 缺口在"出口层"不在"知识层"，脚手架杠杆
  （约束解码/两段式生成）有理论空间，地图记指针（不开训练波）；否 → 命名知识确实缺失，
  X1 结构性定位加固。**两支都有信息**（playbook §1 已落输出离线重判三件套的标准应用）。
- **bf16 消口径列**：评测器加量化覆盖开关（~20min 开发）+ 14B bf16 推理 3-4 集（~40min）；
  预期差 ±1-2 分，把地图读数的"4bit 口径"脚注升级为实测。
- **（可选，条件触发）f1 冠军 seed 复核**：标定 0.800 锚的噪声带。只在 MED-D 读数落在
  守门带边（±2 分内判生死）时必须——R2/R7 预注册的 seed 复核纪律已覆盖，先不占机时。

### 3.4 不做清单（与预注册/红线对齐）

| 不做 | 理由 |
|---|---|
| unseen-F1 的数据攻击（补 singleton 病样本） | X1 结构性（61% singleton）+ MED-C 实证增强范式有 ood 代价 + 语料外数据红线。unseen 的唯一潜在杠杆在脚手架层（待 3.3 离线重判定性），不在训练层 |
| 知识粒度对症合成（教"症状→规范诊断名"） | 疾病级教学对的合成需专家级验证（X2 顾虑的疾病版）+ 边际收益低（epoch 已到 0.863）+ 范式代价已知 |
| β 扫参 / 更多容量档微调 / LLM judge | C-1 平移（β 不敏感）· 档位纪律（中间档不训）· D-04（全确定性判分） |
| 语料扩充（外部病历） | 红线（PROVENANCE+审计）；项目定位是信号榨干非数据扩张；X5 限学习研究 |

## 4. 判定与建议

**继续推进，恰好两波（MED-D → MED-E），然后项目收官。**

- **完成度账**：偏好杠杆是四族唯一空白格；地图 v1 是立项兑现件未产出。两波各 ~1 晚、
  成本低、信息保底（双向枚举 + 量化读数），属"收口感"投资。
- **边际收益曲线**：seen F1 0.800→0.863 耗一整波且带 ood 代价——语料内训练杠杆的边际
  收益已 flatten（0.412→0.800 是数据形态一击，0.800→0.863 是 epoch 堆叠的末梢）。
  MED-D 是最后一个便宜的未测面；此后任何显著提升都需外部数据（红线）或跨层杠杆
  （脚手架，超本仓定位）。
- **定位约束**：X5 限学习/研究、不做临床声明——"更强的模型"不是目标，"完整的地图"才是。
  收官时若触发 D-07 条件（项目延长/换手）再评估 specs/ 拆分。
