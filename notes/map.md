# 杠杆×失败轴地图（罗盘）

> **定位**：本仓的域结论账本——"哪格有读数、谁是主敌、哪层归属"，给未来波的**决策**用；
> 过程教训在 `notes/lessons.md`（给未来波的**操作**用），两者不混写。
> **维护规约**（playbook §5 同规）：波次戳追加续写，过期靠新批声明取代关系，**不原地改写**；
> 每格理想形态 = 读数 · 代价轴 · 适用域 · 归属层（v0 种子先填读数与归属层，代价轴随波补）。
> **版本**：v0 种子 = M0（MED-A 零训练层，2026-09-28）；**v1 定稿 = 2026-09-30（M4 落，
> 四列补齐——G5 兑现件，项目收官 D-08）**。

## 轴与杠杆的坐标系

- **失败轴（五轴）**：①疾病命中（seen / unseen 分列，主轴）②格式合规 ③依据覆盖
  ④鲁棒（garbled / minimal / 无病[未测，X2]）⑤数值幻觉
- **杠杆四族**：容量（五档）· 数据（MED-B 三臂 / MED-C 合成）· 偏好（MED-D）· 脚手架（模板/解码/量化）
- **归属层**：底座先验 / 数据教学 / 偏好校正 / 脚手架——"改善标层归因"纪律的落点

### M0.2 核心洞察（罗盘指针）

1. **契约 ≠ 任务**：格式轴 0.6B 就免费（系统提示内含示例+显式规则），疾病轴 0.6B≈0——
   "会答题卡，不会答题"。数据预算应全押疾病轴；格式护栏降权为防回退监测（已落 MED-B 校准块）。
   适用域：指令底座 + 带示例的显式契约提示。
2. **seen/unseen 断崖是结构性的**（每档 5~8 倍，全档 unseen ≤0.08）——X1 风险实测确认。
   unseen 低不是配方失败的证据；泛化存在性的判据走依据覆盖轴的 unseen 侧（R9 预注册已伏笔）。
3. **主敌是知识粒度，不是命名规范化**：主力失败形态"症状当诊断"全档存在；近失误 42 对候选中
   40 对为粒度/亚型差，仅 2 对命名变体（SYNONYMS 首批即全部）。→ SYNONYMS 工程在本域收益
   极小；F3c（凝练依据=直接教疾病命名收敛）可能比 F2（score 过滤）更对症——R4 的一个预判。
4. **两种"鲁棒"不同层**：garbled 是模式识别级（0.6B 白送），minimal 是知识+推断级（随容量）。
   MED-C 臂设计按层拆分，不打包成单一"鲁棒臂"；无病条件（未测）立项第一动作 = 零样本探针。
5. **幻觉主形态 = 参考值内插**：编造教科书正常参考值当检验结果（Hb 70g/L→140g/L，抽验坐实）。
   安全审计盯"值太正常"，不是"值太离谱"；4B(Instruct-2507) 是唯一 0 起点档，谱系混杂不拆分。
6. **门槛结论对 4bit 量化稳健**：8B/14B 量化口径下容量阶梯仍单调——QLoRA 训练 + 量化推理的
   对照口径可用；MED-B 收官可选补 bf16 评测列消口径差。

### M1.2 核心洞察

1. **score 过滤对 SFT 零增量**（F2≡F1 全轴差 0 分）：SFT 是绝对模仿，好坏链的形态差
   不构成信号；score 信号的价值出口在偏好路径（MED-D）。
2. **冠军 = 主判据 ∧ 护栏合取**：f3c 主判据最优但覆盖破线（凝练删依据细节的机制性
   代价）——详略权衡的量化：+4 分 F1 换 −7 分覆盖。分轴下注时代价轴必须显式。
3. **鲁棒 SFT 存活性随容量分层**：garbled 在 1.7B 回退（复读层被抹）、14B 存活（实质
   理解层）——零样本命中的"层"决定 SFT 后命运（取代 M1-先行第 1 条，14B 验证完成）。
4. **无病条件零样本即会**（反面探针 30/30）：显式契约 + 示例的行为 14B 零冷启动
   （第三次同型预注册错判，见 M0.4 台账补行）；SFT 后边界漂移 1/20（自限痊愈语义）。
5. 容量×数据交互：同数据 1.7B .588 → 14B .800（数据杠杆在交付档放大约 1.4 倍）。

### M2.2 核心洞察

1. **契约出口的用进废退**：语料零覆盖的契约条款（规则 4"无"）在叠加 epoch 后字面粘性
   衰减——cg/cm 出口词漂移为"健康/正常"（语义对、字面违约）；训练分布内含该出口
   （cn）即免疫。**契约行为不是 SFT 免费品，零覆盖出口清单是长训交付的必过门。**
2. **边界语义可教且跨场景迁移**：自限已愈（B 形态）36 条 → 评测 20/20 超锚 + neg-013
   修复 + 场景类型不相交仍全泛化——"痊愈≠现患"是数据可教行为非容量天花板（M1.2-4
   的 5% 微扰有解，解在对症数据）。
3. **增强形态与主判据无冲突**：三臂 val-reg +2.5~+5.0（叠加 epoch 的小幅正贡献），
   经典"联合稀释伤主轴"未出现；代价轴在 ood（三臂等幅降 -5~-8，与增强形态无关 =
   范式代价嫌疑）与覆盖（cm/cn -0.4 分缘破）。**cn-low 鉴别实验坐实**：配比 12↔36 对
   ood 零影响（0.067 逐位同）——ood=范式型代价（续训特化，不可配比修复）；覆盖则随配比
   恢复（0.933→0.958）——覆盖=稀释型代价（可调配比）。**两代价轴可分，处方分家。**
   附带：cn-low ood 覆盖 0.985 > 冠军 0.969 而 F1 .067——退化在"命名泛化"不在"证据泛化"。
4. **不对症增强是负资产**：cg/cm 对已满分轴（garbled/minimal 20/20）补数据零增益，
   反经出口词漂移伤及无病轴——**已满分轴不需要训练分布覆盖来"巩固"，巩固数据的
   边际收益为负**（与 M0.5"翻正无空间"校准互证，但本波实证了反向伤害面）。

### M2.3 设计层指针

- **交付配方维持冠军 f1 ckpt-219**（R5' 终判不过，增强臂不入主线）；**cn-low 为已验证
  分轴组件**（output/med-c/14b-cn-low/checkpoint-219：val-reg .863 全项目最高 · 覆盖
  .958 · 无病轴满分，唯一代价 ood .067；MED-B 时代口径[ood 对零样本 0.072]下全轴过门
  ——两口径差异是 R5' 收紧锚的设计层信息，无病轴有交付需求的配方组装时取此件）。
- **MED-D**：挂点与守门锚随上条；DPO 教学面注意"出口词漂移"——偏好对的 chosen 须含
  契约出口形态（无/数据异常），负侧消退率读数加计出口词形态。
- **MED-E**：全配方列定稿入账时，MED-C 三臂读数入列（合成杠杆一格）。

### M3.2 核心洞察

1. **第四杠杆的兑现形态 = 零代价 seen 侧微增益**：+1.2 F1（2 分等价带内）+ ood 覆盖
   +0.5，全轴无回退——score 信号的偏好路径出口兑现（R4 预注册的双向枚举落地）；
   unseen（ood F1 逐位同）与无病边界不在作用面。**偏好杠杆是"精修件"不是"突破件"**。
2. **adapters 模式 DPO 对契约层安全**（vs M2.1 续训 SFT 的出口漂移 5/7）：三臂出口违约
   0/0、契约行为全保持——对比损失调链间相对概率、不动契约输出形态。**可与冠军叠加的
   无风险层**，M2 的"长训必过零覆盖条款门"在 DPO 形态下自动豁免。
3. **负侧消退率的读数前提 = 起点分离度**：logps 起点 -19.6 vs -55.5（负侧基线已压满）
   → 边际收益必然落正侧证据质量（条目内证据原子覆盖↑而非条目数↑）。预注册读数先量
   分离度，否则"负侧无变化"会被误读为无效。
4. **剂量开关型三域复现**（C-1 姊妹域实验仓 / MED-C 对症数据 12 条 / MED-D 偏好对 3 步）：
   1 步无效 → 3 步饱和 → 9 步零过校正。**跨域默认处方：最小有效剂量 + 饱和即停。**

### M4.3 核心洞察

1. **unseen 断崖的配方结构学**（R9 量化入账）：SFT 数据形态一击不改变断崖率（5.7→6.0×）、
   DPO 零代价不动（6.1×）、**epoch 续训放大**（cn 系 12.9×：seen +6.3 分 ∧ unseen 腰斩）——
   断崖率是杠杆族的签名；放大断崖的杠杆（epoch 续训）与不动断崖的杠杆（adapters DPO）分家。
2. **泛化存在性 = 覆盖轴成立**（R9 判据，同集对照）：10/11 配方 unseen 覆盖 > 零样本 .927
   （唯 f3c .893 破线，与其出局原因一致）——泛化兑现集中在证据组织轴不在命名轴，两轴分叉
   **结构性**；脚手架杠杆 ≈0-3 分不开波（命名/证据分叉 0/60 + 命中 = 基座知识）。
3. **unseen 侧是构造性 100% 疾病零先验**（E1 口径更正，D-09"29/62"证伪）：test-ood =
   全病单例池（R0a 断言）→ 61 处引用全部 train 零出现——X1 知识层定位在**设计层事实**级
   证据上闭合；唯一治本路径 = 外部数据（红线门 → D-09 二期检查点受理）。
4. **量化口径脚注（4bit）的边界条件**：bf16 全量列本机不可行（0.77 tok/s 物理 CPU 墙，
   15-24h，作者拍板弃列，报告 §2 三轮诊断实录）——读数可比性以 4bit 口径成立（全波同口径
   + M0.2-6 量化稳健性），升级路径 = ≥32GB 显存单卡分钟级补测（工具路径已验通留档）。
5. **预写数字要回查设计层断言**（方法论，同步 lessons）：统计口径数字与构造性设计冲突时
   以设计层为准——本案 R0a 断言两分钟终结三处文档的错误数字，且更正方向是强化原结论。
