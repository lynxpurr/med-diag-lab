## 2026-09-27 · 立项批

- **新域立项的第一件产出是"数据体检"而不是"训练配置"**：1337 例逐字段实测（填充率/长尾/score
  分布/重复/None）直接推翻了"照抄官方 SFT 版就能用"的默认路径——官方版浪费了 score 信号
  （176 条 score-1 噪声原样入目标）、reason/conclusion 监督、以及 system prompt 承诺却 0 覆盖的
  三种鲁棒行为。数据体检的事实源入 `research/2026-09-27-dataset-survey.md`，后续所有形态设计
  对着它下注。（出处：本仓 research/ · 上游方法学仓的"审计先行"谱系的立项版）
- **F1 官方式的"逐字节重建校验"是三臂可比性的地基**：build_dataset.py 的 fidelity 断言不只验
  "转换没丢字"，更验**自建目标构造器在官方目标上重建逐字节相等**——F2/F3c 与 F1 的任何读数差
  从此只能来自数据形态本身，不可能来自构造器漂移。（出处：`tools/build_dataset.py` R0b 断言、
  上游方法学仓的对拍器谱系"验证器与被验证物每步变换对齐"的移植）
- **LFS 指针文件的 sha256 即平台侧指纹**：ModelScope 数据集 clone 后主文件是 LFS 指针，其
  `oid sha256` 与 resolve URL 直下文件哈希对账——出处验证不需要平台提供校验和接口。
  （出处：data/PROVENANCE.md 对账表）

## 2026-09-28 · MED-0 补记批（重复组复核）

- **去重键看到的是"冗余"，组内翻开看到的是"双标注"**：condition 哈希把 22 组归为重复，逐组比对后
  发现疾病列表 22/22 全同、分析链 0/22 全同——同病例两套独立推理标注，不是复制粘贴。"这批数据是
  什么"必须翻开看组内差异才能定性，聚合键（哈希/计数）只告诉你"哪些像"，不告诉你"差在哪、为什么"。
  两个动作的分离：**训练侧剔除**（臂间对照的权重公平）与**素材侧保留**（manifest 落语义，供评测/
  偏好对/一致性探针取用）互不矛盾——"没用"说的从来是"对当前训练目标没用"。（出处：
  reports/med-0-data.md §6 补记、split-manifest.json duplicate_groups）
- **生成物的语义修正要用"重跑不扰动"来交割**：改 dedup() 语义后先冻结六 fixture 的 sha256 再复跑，
  逐字节不变才允许 manifest 换结构——修正案的证据不是"代码看起来没改到别处"，是重建产物的指纹
  全等。（出处：tools/build_dataset.py 复跑实录；上游方法学仓的"框架实际生效配置以运行时快照为准"

## 2026-09-28 · 方法论提炼批

- **跨仓迁移的合适颗粒度是"纪律"不是"结论"**：从上游方法学仓的全谱提炼 playbook 时，可平移的
  全是判读纪律（预注册怎么写、读数怎么分轴、审计什么时候做），不可平移的全是域结论（哪个秩在
  哪个轴几分）——因为上游方法学仓自己的教训就是"判决有适用域，被后续判决重新框定"。提炼动作
  本身因此也要按域裁剪：姊妹域实验仓的"表述形态×单位"到了本仓要翻译成"检验值表述形态"，机械照抄
  条目名会造出看起来迁移、实际不对症的假地图。（出处：notes/playbook.md、上游方法学仓 lessons
  H 收束批"适用域"条）

## 2026-09-28 · MED-A 零训练基线批

- **gold 自校准门在"规格层"就开工抓 bug，不必等模型**：评测器 v1 按 HANDOFF 卡片细则实现，
  gold 门第一次跑就抓出"目标内无中文分号"会把 gold 自己判败（依据散文的中文分号是合法中文
  标点）——卡片细则≠可判分口径，铁律的价值不在验证代码没 crash，在逼规格歧义在零 GPU 阶段
  显形。本波三处口径修正（②收窄块内、⑤单位词表、v1.1 剔除个/次）全部来自 gold 门 + 人核
  回路，没有一处来自模型输出。（出处：reports/med-a-baseline.md §1、tools/run_eval_med.py
  docstring 修正记录）
- **"数值+单位"原子的单位表是判分口径不是字符类枚举**：`个`/裸`次` 看起来是无害的计数单位，
  实际会把"1个月""5～6次"切成假原子——症状史计数复述与检验值在安全语义上不同类（X5 防的是
  编造检验值），单位表必须按**语义类**（检验/体征值）白名单而不是按"像单位"枚举。年龄的
  "N岁 vs 年龄：N"在场感知同理：归一化要懂字段结构，不只是字符串变换。（出处：v1.1 修正 3、
  轴③人核校准 rec-1303/1034/0829 三例）
- **序列长度要 tokenizer 实测，字符数估算会错一个截断量级**："本仓序列 <1K token"的注记
  （字符视角的直觉）实际是 **1096~1725 token 全量超 1024**——照抄上游方法学仓的模板
  `--max_length 1024` 会静默截断每一条训练目标。对拍器在 max_length 处直接抛
  MaxLengthError 反而是最便宜的暴露方式。（出处：check_template_med.py 开发实录、
  F1 全量 token 分布实测）
- **预注册预期错一半是健康读数，不是流程失败**：R1 四预期中②④（格式冷启动、鲁棒全挂）被
  实测决定性推翻（格式全档 94~100%，garbled 全档满分）——系统提示里带完整示例的契约对
  现代底座不是冷启动；写死预期的价值恰恰是把"我没想到"变成"我预判错了什么"的可枚举清单，
  校准块接着把错判翻译成 MED-C 的设计变更（对症轴从翻正改为保持，重心移无病条件）。
  （出处：reports/med-a-baseline.md §3、playbook §1 校准块条）
- **4B 槽位谱系混杂要在读数表里显式标注**：Qwen3-4B-Instruct-2507 与同族 hybrid 档不同谱系
  （另加 qwen3_nothinking 模板），其幻觉离群（参考值内插 15+23 原子）无法在"容量"单变量下
  解释——跨档比较表带 caveat 列，否则容量阶梯会被谱系差污染。（出处：med-a-baseline.md §5）
- **贴边推理的降批要降到底再谈等待**：14B 4bit 在 11.4GB free 下 batch4 于 52/80 OOM，
  batch1+expandable_segments 通过且仅慢 ~2 倍——"降批重试"比"挂待 GPU"先试，等待是最后
  手段（本波 15 列因此全部当日收齐，无一列挂起）。（出处：matrix-run.log 14b 三列实录）

## 2026-09-28 · 容量阶梯方法论批（问答回收提炼）

- **容量阶梯是测量投资，不是训练路线**：五档阶梯的价值结构 = ①把"不会"拆出归属层
  （脚手架层：提示词可解，勿用数据教；知识/容量层：唯一数据主战场；模式识别层：小档白送
  ——全表见 map M0.1）②给数据动作定价：门槛之下数据被静默吃掉不报错（上游方法学仓实证
  同数据 1.7B 0/7 / 14B 6/7），没有阶梯会把"容量不够"误诊为"数据没用"然后去改数据
  ③跨档逐位同错 = 数据构成指纹判据（需 ≥2 档同超参族）④单调未饱和 = headroom 与每档
  基线锚（G3"显著超同底座零样本"的分母）。测量做在训练之前，之后每个读数从"一个数"
  升级为"有归属层的数"。（出处：playbook §5 阶梯读法条、map M0、MED-A 报告 §3/§4）
- **阶梯砍到两端，不逐档训**：零训练阶梯给中间档定价后，4B/8B 无独占行为层（不比 1.7B
  多出新层次、不比 14B 多出新空间）——全训 5 档 × 3 臂 = 15 run 买重复信息。两级设计
  （1.7B 容量敏感边缘探针 + 14B 交付档）覆盖全部判据需求；阶梯答"门槛在哪"，不答"最佳
  配方是什么"——配方搜索留在交付档单档展开。（出处：PLAN §4 MED-B 两级设计、
  playbook §5 既有"两级快筛槽级读数"条）
- **否定性设计决策要与肯定性描述同响度**：项目主人的第一反应也是"我们每次微调从 0.6
  开始逐次加到 14B"——五档零样本在报告与对话里曝光度高，而"微调只走两级"藏在开工卡的
  "不做"列表里不显眼，读者记忆会自动把"跑了五档"补全成"训了五档"。修复动作：skill §3
  显式加"档位纪律"行（微调只走 1.7B→14B；五档全阶梯属零训练测量）。教训：**"不做什么"
  若只在越界条款里出现，它的传播力就只有越界条款那么大**——影响资源分配的否定性决策
  （不训哪些档/不跑哪些臂）要在操作入口（skill/run 模板）重申。（出处：2026-09-28
  问答回收，skill §3 已补）

## 2026-09-28 · MED-B 快筛批（进行中·1.7B F1 臂）

- **零样本"已会"要看层——规则复读层会被 SFT 抹掉**：garbled 命中 20/20 → SFT 后 0/20，
  细分形态是"识别在、契约出口错"（依据明说乱码却走 `无;` 不走 `数据异常;`）——零样本命中
  本是回声句式不是理解，训练数据零覆盖该行为，复读通道被数据分布自然淘汰。次级形态：
  1 例复读 system prompt 示例答案（输入-fewshot 干扰型幻觉）。**判读规则：门槛表的"已会"
  必须带能力层注（map M0.1 已注），且复读层的"已会"对 SFT 设计的含义是"必须补数据否则
  必回退"，不是"白送"**。MED-C 对症轴设计依据由此改写。（出处：reports/med-b-sft.md §2、
  score-sft-1p7b-f1-test-rob.json resp 抽查）
- **SFT 教得动结构、教不动分布外推断，同一次训练即可分层读**：1.7B F1 臂同 run 内——
  格式/条目粒度（P=R=0.588）/幻觉（15→0）/覆盖（+0.022）全面收敛，unseen F1 原地
  （0.031→0.050）。与 X4 人核互证：chosen 优势形态 = 条目粒度+证据类型递进，**这份数据
  在 SFT 路径卖的是结构完整性不是医学洞察**——对 MED-D 的含义：DPO 能教的也是结构层，
  R8 读法按此预期。（出处：reports/med-b-sft.md §2、research/2026-09-28-x4-pairs-worksheet.md
  回填）
- **预检门阈值是实测资产，不是乐观估计**：run_med_b.sh 初版 NEED=11200 放行了 free
  11477 的贴边档，14B bs1@2048 首步 OOM（常驻外 11.25GiB，进程 11.20GiB 差 42MiB）——
  已修 12300 对齐"常驻外 ≥12GiB"红线。**预检门的语义是"实测峰值需求 + 余量"，抄历史
  乐观值（13.4GB 锚是 1024 时代 bs2 峰值）等于把门卸了；OOM 在第 0 步炸是运气，在
  epoch2 炸才是常态**。（出处：output/med-b/14b-f1-oom-0928/ 归档、tools/run_med_b.sh
  头注）
- **ckpt 评测的防漂移 = 配置从训练快照恢复**：评测器 adapters 模式让模板/量化/思考开关从
  ckpt 同级 args.json 自动恢复并打印核对——评测配置与训练配置的漂移从"靠人记住"变成
  "结构性不可能"；配套纪律：改评测器后 gold 门必复跑（本次照走，三集全满分）。
  （出处：tools/run_eval_med.py adapters 分支、run_eval_b3.py 谱系）
- **"人核"由模型执行时，身份与可抽查面必须显式入账**：X4 三十对判定由 GLM-5.3 出具，
  回填行标注判定者身份 + "非平凡判定仅 9 行（N/B 与非 T），抽查成本刻意压到最小"——
  模型初判的证据价值 = 判定者身份透明 + 复核成本最小化设计，否则下游会把它当人核引用。
  这是"审计先行"在 agent 执行时代的身份纪律。（出处：research/2026-09-28-x4-pairs-worksheet.md
  回填区）

- **术语溯源是方法论的自检入口，不是辞藻**：被问"医学微调为什么用'三臂'"，认真作答就把

  （防事后合理化）、主判据/护栏 = primary endpoint / safety margin、臂间差 <2 分等价带 =

## 2026-09-28 · MED-B 执行批（B4 评测与探针准备期）

- **路径分隔符会污染文本工具的字段切分——选择器必须带"选中即校验"硬门**：B4 脚本
  `sort -t- -k2` 想按 checkpoint 序号排序，但路径 `output/med-b/14b-f1/checkpoint-73` 里
  `med-b`/`14b-f1` 的连字符打乱字段切分，epoch-1 的 checkpoint-73 被**静默**当末步选中
  （73 > 146/219 仅因字典序"7">"1"）。止损靠人工瞄到进程命令行；修复 = `sort -V`
  （数值感知）+ "末步必为 219，非 219 即拒跑"硬门——**选择器再坏会大声失败而不是静默
  选错**。凡"从列表选一个关键物"（ckpt/文件/行）的逻辑，产出端必须挂可断言的期望值。
  （出处：tools/run_med_b4.sh 修复实录）
- **复用解析器前先查它的口径假设——哨兵过滤也是口径的一部分**：轴⑥无病判分初版复用
  `parse_diseases_tag`，而它按轴①口径把"无/数据异常/缺少关键诊断信息"当哨兵词过滤

  MED-C 先例授权只覆盖作者自己的兄弟项目 systemd 服务——按归属分级处置：自己的
  user unit（先例内，可停可复）> 共享 docker 栈（越界，不动）> 兄弟 agent 会话进程
  （不可控，等窗口）。最终用训练侧适配（cap1350）+ 等待循环解决，代价多两小时但
  零越界。**资源紧张时的"快解"若越授权边界，先问再动**。
  （出处：med-d 报告 §2、§5 GPU 债务注记）
- **开工前审计的复利：X4 两读数各省了一整层**：①A 源 score 信号可信（Y 96.7%）→ D1 的
  300 对直入、零追加人核；②B 源 T 异常多（14/20 平局）→ 双标注预算开工前就下调至 6 对、
  A 源补位——两个读数都是 2026-09-28 预付的，2026-09-30 波里全额兑现。"对症点保质期"
  纪律（审计贴着开工做）的另一面是：**审计结论要写成可执行的预算决策**（信多少对、
  哪个来源补位），而不是只写"信号可信/不可信"的形容词。
  （出处：research/2026-09-28-x4-pairs-worksheet.md 回填区、med-d 报告 §1）

## 2026-09-30 · MED-E 收官批（收官波三教训）

- **"开关已开发" ≠ "读数已定价"——增件的执行成本要在首个现实门实测**：bf16 消口径列按
  D-08"零成本读数"入卡（开关开发 20 分钟已付），但首跑实测 0.77 tok/s 物理 CPU 墙 →
  全量 15-24h，超预算 10 倍。smoke 小样（--limit 2）正是干这个的：它不只是"验通"，更是
  **定价门**——拍板（弃列/妥协/过夜）在实测数字上做，不在预注册假设上做。增件入卡时
  把"成本实测"写进第一个 gate，预注册预算当假设不当承诺。
  （出处：med-e 报告 §2 三轮诊断实录、作者四选一拍板）
- **offload 推理三段排障序：OOM → 页抖动 → CPU 墙**：①整装 OOM（caching_allocator_warmup
  要 14.27GiB > 空闲 10.99GiB）→ 加 device_map auto；②裸 auto 在 swap 满的机器上是隐坑：
  CPU 侧层留 mmap 页（进程 RSS 仅 530MB 不涨），症状 = GPU 0%/线程全闲/200s 级每条——
  RSS 不涨就是"权重没实体化"的警报 → 显式 max_memory 落 int 键（JSON 串键被 accelerate
  拒）；③实体化后 load 14.5/16 核 + GPU 0% = CPU 算力墙，到此软件无空间，认账走人。
  （出处：med-e 报告 §2、e2-smoke*.log）
- **统计口径数字与构造性设计冲突时，回查设计层断言（两分钟终结三处文档错误）**：D-09
  "test-ood 62 处引用 29 处零出现"被 build_dataset.py 的 R0a 断言（train∩ood 疾病集 = ∅）
  直接证伪——真实口径是 61 处引用 100% 零出现（构造性）。跨波引用的数字必须能回到
  断言/生成器复算；本案更正方向还是**强化**原结论（X1 加固），证伪不总是否定。
  （出处：med-e 报告 §1.3、map M4.3-5）

## 2026-09-30 · 项目收官总回收批（跨波形态规律，单波 lessons 装不下）

- **同型预注册错判三连，第三次才立规则——错判同型第二次出现就该升级**：格式冷启动
  （R1-②）、garbled 全档满分（R1-④）、无病探针 30/30，三次全是同一形状：低估"显式
  契约 + 示例"行为的零样本能力。前两次各记各的台账，第三次才现场降档改设计——**同型
  错判的第二次就应该触发设计层默认反转**（押"零样本会"，探针先行）。台账要按"形状"
  归档不是按"波次"，否则形状要撞三次才被看见。（出处：map M0.4 台账三行、med-c
  无病臂降保持档实录）
- **收官判据前置是六波不粘锅的原因**：D-08 三账合算（信号残量/杠杆完成度/边际 flatten）
  预注册了"恰好两波后收官"——MED-E 末波没有发生"再试一轮"的拖延，也没有"仓促收工"
  的遗漏；bf16 增件超预算 10 倍时走显式四选一拍板，而非沉默砍掉或硬跑。"什么时候停"
  写进计划，和"做什么"写进计划，是同一件事。（出处：PLAN D-08/D-09、med-e 报告 §2）
- **迭代载体与叠加分界（二期/新域项目设计时直接取用）**：迭代的载体是数据与配方在
  底座上重演 + 每轮全回归守门，不是 checkpoint 滚雪球——同目标加数据挂冠军续训 =
  范式代价（MED-C 实锤），换目标管线叠加（SFT→DPO）= 零代价（MED-D 实锤）；数据量
  大时重训常优于续训。终态交付 = 主配方 + 分轴组件 + 组装查询表（map M4），非单体。
  （出处：M2.3/M3.3 两波对照、playbook §7）
- **口径资产复利实录**：判分单一事实源（score_item + normalize）在仓内复用四次——gold
  自校准门 / 造数 fidelity 反向门 / 离线重判与分层读数 / 出口形态扫描。评测器先行省下
  的不是一次开发，是每波一次的验证重建。新项目第一件写评测器 + gold 门，不是训练脚本。
  （出处：tools/run_eval_med.py 全谱系调用点、augment_med_c gate()、med_e_stratify.py）
