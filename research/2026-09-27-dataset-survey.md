## 1. 数据集体检（实测事实）

### 1.1 结构与体量

- **1337 例**中文病历，四部分：`condition`（12 字段病历）、`diseases`（疾病标签）、`analyses`（带 1–3 评分的病例分析链）、`diagnoses`（reason 诊断依据 + conclusion 结论）。
- 官方另附 SFT 版（1337 行 messages 格式）：system prompt（1316 字，规定 `<diseases>` 输出契约 + 分条依据）+ 渲染病历 → 目标 = 疾病列表 + 全部分析拼接。
- **序列极短**：输入病历 mean 120 字 / p95 243 / max 523；诊断输出 mean 156 / max 417 字。全序列 < 1K token——**训练极便宜，16GB 卡无压力**。

### 1.2 字段填充率（N=1337）

| 字段 | 填充率 | 字段 | 填充率 |
|---|---|---|---|
| chiefComplaint 主诉 | 100% | physicalExamination 体格检查 | 75.2% |
| age 年龄 | 96.5% | auxiliaryExamination 辅助检查 | 56.2% |
| gender 性别 | 92.1% | pastHistory 既往史 | 18.3% |
| historyOfPresentIllness 现病史 | 88.4% | personalHistory 个人史 | 6.7% |
| pregnancyAndDelivery 婚育史 | 2.6% | reproductiveHistory 生育史 | 2.0% |
| epidemicHistory 流行病史 | 0.7% | allergicHistory 过敏史 | 0.4% |

核心四字段组合：主诉+现病史+体检+辅检 507 例；主诉+现病史+体检 373；主诉+现病史 138——**天然的"信息完整度阶梯"，天然的缺失场景素材**。

### 1.3 疾病标签：深长尾

- 总诊断 1398 条，**唯一疾病 710 个，436 个（61%）只出现 1 次**；每例 1.05 个病（max 4）。
- 高频头部：溃疡性结肠炎 16、急性胰腺炎 14、缺铁性贫血 13……内容风格是教科书/病例分析题式的典型病例（含霍乱、伤寒、麻疹、新生儿疾病等），**来源为个人上传，内容出处不可独立核实**。
- 按记录的主疾病频次分桶：singleton 381 例 / 2–3 次 424 / 4–10 次 444 / >10 次 88。
- **381 例的全部疾病均为 singleton** → 天然的 unseen-disease OOD 评测池。

### 1.4 analyses：被官方 SFT 版浪费的核心信号

- 6726 条分析（每例 3–9 条），score 分布：**3 分 5017 / 2 分 1523 / 1 分 186**。
- 官方 SFT 目标把**所有** analyses 无差别拼接（分条数 = analyses 数，逐条验证 0 偏差）——**score 信号完全没用上**：176 条记录的 score=1 低质推理被原样教给模型。
- **record 内同时含 score≤2 与 score=3 的记录 1206 例；含 score=1 与 score=3 的 176 例** → 天然的 record 内偏好对（chosen/rejected 同 prompt 不同推理质量），比 LAB-G 用负例生成器造对更干净。

### 1.5 diagnoses：第二套未被用的监督信号

- 13 例 `diagnoses=None`（官方 SFT 仍用 diseases+analyses 出目标，不受影响）。
- **78 例 `diseases` 列表 ≠ `diagnoses.conclusion` 列表**——conclusion 更细（并发症/亚型：如"肠梗阻"vs"合并急性肠梗阻；继发局部感染"）。两套标签粒度并存，教哪种是**设计决策**不是搬运。
- `reason` 是凝练版依据表述（vs analyses 的完整推理链）——**同一病历两档"依据详略"教科书**。

### 1.6 数据质量风险清单

| # | 风险 | 实测 | 处置 |
|---|---|---|---|
| Q1 | 完全重复记录 | 22 组、23 条冗余 | MED-0 去重（保留先出现者，指纹入 PROVENANCE） |
| Q2 | 长尾记忆/泛化混杂 | 61% singleton 疾病 | 分层切分 + seen/unseen 双口径评测 |
| Q3 | 同病跨集泄漏 | 主诉重复 top 6 次 | 疾病粒度切分 + 重复组原子化（同组同集） |
| Q4 | 疾病名不规范 | "门脉性肝硬变"等旧教材术语 | MED-0 做结论规范化映射表（评测口径，不改训练原文） |
| Q5 | system prompt 承诺的行为 0 覆盖 | 无病/数据异常/缺关键信息三类在 1337 例中 **0 条** | MED-C 合成三臂（LAB-E defaults 谱系对症） |
| Q6 | 版权/出处 | 个人上传，内容疑源自教材例题 | 学习/研究用途 OK（与上游方法学仓学习导向一致）；**不用于任何临床部署** |
| Q7 | 医学安全 | 诊断输出直接面向疾病结论 | 输出契约保留"依据先行"，评测含编造检查项检测；产物标注"非临床用途" |

## 2. 官方 SFT 版的利用盲区 = 我们的多余量

官方版本只实现了数据集**一种**用法（全量拼接教一个任务）。可榨出的额外价值：

1. **score 加权/过滤**：只用 ≥2 分分析，或 3 分优先的目标重排（176 条记录的 score-1 噪声清除）。
2. **详略双档目标**：analyses 全链（详）vs diagnoses.reason（略）——同一病历教两种输出形态，或做课程学习（先略后详）。
3. **conclusion 细粒度标签**：78 例的并发症/亚型信号。
4. **record 内偏好对**：1206 例 score 混合 → DPO 直接成对，无需负例生成器。
5. **评分任务**：给分析打分（critic）——3 分类，6726 条监督。
6. **字段完整度阶梯**：天然缺失场景 → system prompt 第 6/7 条行为（信息不足时推测/声明缺关键信息）的对症素材。
7. **三无场景合成**：无病/乱码/极简输入——LAB-E `augment.py` 五模式 + 护栏谱系直接换语料。

### 3.2 直接迁移的结论（省掉的试错）

- **LoRA 配方起点**：r16/α32 是行为轴稳妥档；r64 必须保 α/r=2.0；14B QLoRA bs2×accum8 一次过的显存账（13.4GB 级）直接可用——本数据序列更短，更宽裕。
- **DPO 剂量学**（G-4/C-1 实测）：lr 5e-6、**先扫步数不扫 β**（步数是开关型：3 步压满行为、9 步伤 solve）；起点分离现象（chosen 已高概率）→ 评估看负侧消退率。
- **容量门槛前置问句**："这个底座不用教就会几条？"——MED-A 零样本基线先行，行为轴数据动作在门槛之下的底座上不计价。
- **联合 SFT 轴间稀释**（G-2）：行为数据会吃缺省数据——多任务混料方案必须分轴验收，预注册"任一掉"分支。
- **T-5 主宾换位**：OOD 评测集启用那天起，预注册判据主轴切到 OOD、分布内降为护栏（≥线下限）。

### 3.3 需要新建的（姊妹域实验仓的地图不覆盖医疗域）

- **新失败轴地图**（本项目的核心知识产出形态）：初版四轴 = **疾病命中 / 格式合规 / 依据质量 / 鲁棒行为**，每轴再分 seen/unseen-disease 两层。
- **确定性评测器**：`<diseases>` 正则解析 → 集合级 precision/recall/F1（结论规范化后）；格式轴全规则判；依据质量轴用"关键证据覆盖"规则代理（reason 中的体征/检查项命中数）+ 抽样人核——**比姊妹域实验仓的 L3 判分更干净，全链零 LLM judge 可达**。
- **对拍器**：medical 版 check_template（qwen3 模板 + `default+ignore_empty_think` 实效口径，谱系第四次复用）。

## 4. 数据充分利用方案

### 4.1 切分设计（MED-0 产出，疾病粒度防泄漏）

```
1337 例 → 去重(-23) → 1314
├─ train        ~1050  (seen-disease 学习集，含全部多频次疾病)
├─ val-reg      ~80    (seen-disease 回归评测：同病不同例，按频次桶分层抽取)
├─ test-ood     ~60    (从 381 全 singleton 池抽：unseen-disease OOD 主战场)
└─ test-rob     ~40    (鲁棒行为评测：合成无病/乱码/极简三条件 + 人核)
```

- 切分以**疾病集合**为原子（某疾病的所有例同集，多病记录按主病归属）；重复组原子化。
- test-ood 的 60 例从 381 池按科室/字段组合分层抽样；池中其余留作扩展。
- seed `20260925` 沿用，SHA256SUMS + PROVENANCE.md 入 `data/`。

### 4.2 五种数据形态（一个数据集五种教法）

| 形态 | 构成 | 教什么 | 波次 |
|---|---|---|---|
| F1 官方式 | 去重全量，score 无关 | 复现锚（对照官方 SFT 版） | MED-B 臂1 |
| F2 质量过滤 | 仅 score≥2 分析入目标 | 清噪声：176 条 score-1 排除 | MED-B 臂2 |
| F3 详略双档 | 同病历 reason 版（略）+ analyses 版（详）双目标 | 输出详略可控 | MED-B 臂3 |
| F4 鲁棒三臂 | 无病/数据异常/极简输入 合成各 30–40 条 | system prompt 承诺的 0 覆盖行为 | MED-C |
| F5 偏好对 | record 内 chosen(3 分链) vs rejected(≤2 分链)，~1200 对潜力先取 300 | 推理质量偏好 | MED-D |

### 4.3 评测器（run_eval_med.py，参数化谱系第三次复用）

五轴读数，全部确定性：
1. **疾病 F1**（主轴）：结论规范化映射 → 集合 F1，分 seen/unseen 两层报。
2. **格式合规**：`<diseases>` 可解析、英文分号、分条序号——L1 级。
3. **依据覆盖**：reason 关键证据项（体征/检查值）在生成依据中的命中率。
4. **鲁棒行为**：三条件各自的目标类别命中率（无→无；乱码→数据异常；极简→推测/缺关键信息）。
5. **幻觉检测**：生成依据中未出现在输入病历的检查值/体征计数。

## 5. 波次计划（预注册骨架，~5 晚机时）

| 波 | 内容 | 预注册判决（骨架） | 机时 |
|---|---|---|---|
| **MED-0** 数据基建 | 去重/规范化/分层切分/五形态转换+自检/PROVENANCE | 切分零泄漏（疾病粒度断言）；转换 fidelity 自检全绿 | 0 GPU，半晚 |
| **MED-A** 零训练基线 | 0.6B/1.7B/4B/8B/14B 零样本五轴读数（**容量门槛前置问句**） | 判"哪些轴底座已会、哪些是 0 起点"——决定 MED-C/D 的底座档位；预期 14B 零样本疾病 F1 已不低（教科书病） | ~1 晚推理 |
| **MED-B** SFT 主线 @14B r16/α32 | 臂1 F1 / 臂2 F2 / 臂3 F3（1.7B 快筛先行探容量敏感） | 主判据 = val-reg 疾病 F1；护栏 = 格式 ≥95%、依据覆盖不降；臂间差 <2 分视为等价（seed 复核后再判） | ~1.5 晚 |
| **MED-C** 鲁棒三臂 | F4 三条件 30–40 条/臂，挂 MED-B 冠军 | 对症轴翻正 ∧ 其余轴零漂移（**反向校验**，LAB-E R6 谱系） | ~1 晚 |
| **MED-D** DPO 剂量 | F5 偏好对，3 步起步，步数阶梯 1/3/9 | 主轴 = test-rob 命中 + 依据质量；**守门 = val-reg F1 与格式不回退**（DPO 过校正吃契约行为的 G-4/H-C1 教训前置） | ~1 晚 |
| **MED-E** OOD 收官 | test-ood 60 例全配方列读数 + 长尾分析 | seen/unseen 差距量化；unseen F1 低预期内（判"泛化推理"存在性），产出本项目自己的**杠杆×轴地图 v1** | 半晚 |

预算口径：14B QLoRA 每 run ≈ 84 步/epoch × 3 ≈ 250 步，序列 <1K token，估计 <1h/run；1.7B 快筛 ~5min。全程 5 晚内，符合上游方法学仓"无一段超预算裁线"纪律。

## 6. 立项建议（待拍板项）

1. **仓位**：建议 `med-diag-lab/`（沿用上游方法学仓的目录范式：PLAN/HANDOFF/tools/reports/data/notes），或作为上游方法学仓的新 LAB 段——前者更干净（新域新地图），后者省环境。**推荐独立仓**，`data/PROVENANCE.md` 记本数据集指纹与下载命令。
2. **底座默认**：主线 14B（行为轴容量门槛），快筛 1.7B，4B-2507 备用（instruct 变体，ep1 loss 最低先例）。
3. **MED-A 的零样本读数出来后再定 MED-C/D 细节**（校准块机制：设计层可校准、判决层冻结）。
4. 风险声明：数据出处不可独立核实 + 医学域——**产物限学习/研究用途，不做临床声明**。
