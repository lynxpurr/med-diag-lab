## 4. R5'/R6 判决（按 PLAN §4 MED-C 校准块原文逐条落）

**R6（挂冠军 ckpt-219 追加 LoRA，不重训底座）**：成立——args.json adapters 落档 + 首步
loss 0.093 低位（冠军末段 0.077 同水位）+ 三臂超参与冠军全同（臂间唯一变量 = 增强形态）。

**R5'（三条件保持 ∧ 主判据零回退 ∧ 其余轴零漂移；双向枚举）逐臂落**：

| R5' 条款（冠军锚） | cg | cm | cn |
|---|---|---|---|
| garbled ≥20/20 | 20/20 ✓ | 20/20 ✓ | 20/20 ✓ |
| minimal ≥20/20 | 20/20 ✓ | 20/20 ✓ | 20/20 ✓ |
| 无病 ≥19/20 且 neg-013 不恶化 | 13/20 **✗** | 15/20 **✗** | 20/20 ✓（neg-013 修复） |
| val-reg F1 ∈ 0.800±2 分 | 0.850（+5.0，带上沿之外·非回退方向） | 0.850（同左） | 0.825（+2.5，同左） |
| 格式 100% | ✓ | ✓ | ✓ |
| 覆盖 ≥0.937 | 0.976 ✓ | 0.933 **✗**（-0.4 分破线） | 0.933 **✗**（-0.4 分破线） |
| 幻觉 0 | ✓ | ✓ | ✓ |
| ood 不劣化超 3 分（≥0.103） | 0.083 **✗**（-5.0） | 0.050 **✗**（-8.3） | 0.067 **✗**（-6.6） |
| **判定** | **不通过** | **不通过** | **不通过** |

- 主判据条款读法：三臂 0.825-0.850 全在等价带**上方**——"零回退"意图成立（无回退方向
  偏离），带外上方按 R2 谱系读法记"主判据不降反升"，不判败；本波判败项 = 无病（cg/cm）
  + 覆盖（cm/cn）+ ood（三臂）。
- **回退分支触发与执行**：按预注册双向枚举——"任一回退 → 联合稀释实证（playbook §4
  谱系），合成配比下调重跑一次，不扫参"。重跑 = **cn 臂 12 条**（A4/B6/C2，36→12；
  cg/cm 不重跑：无独占教学载荷且其失败轴是无病回退，低配比无修复路径）。

**R5' 终判（重跑后）**：cn-low 逐条款——garbled 20/20 ✓ · minimal 20/20 ✓ · 无病
20/20 ✓（neg-013 保持修复，出口词零漂移）· val-reg 0.863（+6.3，带外上方，零回退
方向不判败）· 格式 100% ✓ · **覆盖 0.958 ≥0.937 ✓（低配比恢复）** · 幻觉 0 ✓ ·
**ood 0.067 ✗（-6.6，与 cn36 逐位相同——唯一残余判败项）** → **R5' 终判不通过**。

- **配比鉴别实验结论（重跑的判据价值）**：12↔36 配比对 ood 零影响（0.067 = 0.067），
  叠加 cg 0.083 / cm 0.050（三种增强形态等幅降）——**ood 代价与增强形态、配比均无关，
  归因为续训范式属性（叠加 3ep + 数据重排的 seen 特化），"联合稀释"标签在此不成立**
  （主判据未稀释反升，稀释轴不在主判据）。预注册响应执行完毕（重跑一次、未扫参），
  判决层定格：**合成增强的泛化巩固在"冠军之上续训"范式下不成立；无病轴对症教学成立
  且配比 12 条即可，代价轴 ood 为范式不可配比修复项。**
- 读法注意（不改变判决）：cn-low 若按 MED-B 时代护栏口径（ood 对零样本基线 0.072 不
  劣化超 3 分）则 0.067 全轴通过——R5' 把 ood 锚收紧到冠军 0.133 是本波判败的唯一来源；
  两口径的差异是设计层信息（见 §6/M2.3），不是判决层歧义。

## 5. 随判观察（判决外关键读数）

1. **对症增强教得动：cn 20/20 超锚 + neg-013 修复 + 出口词零漂移**。探针期冠军在
   negt B 形态 3/16 现患化 + neg-013 现患化，训练 36 条（B16）后评测集 20/20——
   "已缓解≠现患"的教学可教且迁移到评测集（评测场景类型与训练不相交，A/C 族全泛化）。
2. **不对症增强反伤契约：出口词漂移（新失败形态）**。cg/cm 的 neg miss 主形态 =
   `<diseases>健康;</diseases>`/`正常`（cg 5/7、cm 2/5）——语义对、违反规则 4 字面。
   机制读法：语料对"无"零覆盖，冠军的 无 行为纯靠显式契约维持；**再叠 3 个 epoch 的
   从未含 无 样本的训练，契约字面粘性被磨掉**（用进废退）。cg/cm 未训无病所以受伤；
   cn 训了所以免疫——契约行为的保持需要训练分布内持续出现该出口。
3. **ood 三臂同降（-5.0/-8.3/-6.6）与增强形态无关**（garbled/minimal/neg 三种形态
   等幅）→ 倾向"叠加 epoch + 重排"的范式代价而非增强内容稀释；ood n=60 单例病、
   F1 粒度 ~2-3 条/档，噪声敏感（MED-B 三臂自身 0.083-0.133 波动带）。**cn-low 重跑
   鉴别实验坐实**：配比 12↔36 对 ood 零影响（0.067 逐位同），范式代价实锤、配比不可
   修复。附带读数：cn-low 的 ood **覆盖** 0.985 反而高于冠军 0.969——单例病的证据复述
   在涨、疾病命名在掉，退化的是"命名泛化"不是"证据泛化"（MED-E 泛化存在性判据的
   R9 侧伏笔：覆盖轴 unseen 侧读数应单独看）。
4. **覆盖两臂破线（0.933 vs 0.937）**：均为 -0.4 分边缘破线，机制同向于 epoch 叠加
   （依据复述风格收敛），与 f3c 的机制性破线（凝练删证据）不同型；**cn-low 低配比
   恢复至 0.958**——覆盖对配比敏感（36 条增强挤占依据复述形态），ood 不敏感：两代价
   轴可分（覆盖=稀释型可调配比，ood=范式型不可调）。
5. **主判据 +2.5~+6.3**：叠加 epoch 对 seen 分布 F1 有小幅正贡献（cn-low 0.863 为全
   项目最高，超 MED-B f3c 的 0.840）——但以 ood 为代价，"多训有害轴"读法入 map
   （分轴下注的代价轴实证）。
