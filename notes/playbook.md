> 提炼：2026-09-28，源 = 上游方法学仓（作者未公开的实验仓；LAB-0/A/B/D/E/F/G/H 全谱 lessons + PLAN + 工具谱系）。
> 原则：**纪律迁移、结论不迁移**——姊妹域实验仓的配方读数（哪个秩哪份配比在哪个轴几分）对本仓无效，
> 产生那些读数的判读纪律全部适用。canonical 出处一律指回上游方法学仓，本手册是操作级展开，不是事实源。

## 1. 开工序与判决纪律

- **预注册判决双向枚举**：判决规则在跑前写死，且"变好/变差"两支各预设支持与排除什么——单向枚举会让
  反向结果被误读成"未破"（E-1 的 r64 假象教训）。→ MED-B R2~R4 / MED-D R7~R8 全部按此写。
  （出处：lab-e-intervention.md §0、lessons E-1b 补课批）
- **"不跑"分支与门控变量一样值钱**：什么条件下弃跑写进预注册（省机时 + 防 scope creep）；门控过而
  子预测未中时照规则放行——临场加严/放宽都是事后合理化的入口。→ MED-C/D 的臂取舍。
  （出处：PLAN §4 LAB-F R9、LAB-G R11）
- **校准块机制**：中期证据的合法出口在设计层（改臂选/底座/对症重心），判决层冻结——R1 读数偏离
  预期时只动 MED-C/D 设计，不动 R1 原文。→ 已入 PLAN MED-A 校准块条款。
  （出处：lessons G 收束批⑤）
- **零训练判决先行**：每波开工序显式问"有多少判决可以不动 GPU 先拿"——标准三件套 = 存量补测、
  已落输出离线重判、审计 diff。→ MED-A 整波即此原则；MED-D 的 30 对人核同理。
  （出处：lessons H 收束批①）
- **审计先行，对症点有保质期**：立项文档里的失败归因是旧评测列的快照，每波修复后残余失败会收敛到
  更细亚型——亚型级数据动作开工前必须用最新输出重做失败形态 diff，立项归因只当历史线索。
  → MED-C 三臂造数前、MED-D 偏好对选定前各适用一次。
  （出处：lab-g-audit.md §1/§3、lessons G 收束批②）
- **seed 复核计划外翻正**：预注册对称结果的信度 > 单样本计划外翻正；后者只标记"处于翻越边界"，
  入结论前换 seed 复核（一次小机时换结论固化）。→ MED-B 臂间差 <2 分时的处置已写入 R2。
  （出处：lessons G 第一批①）
- **失败实验产物是资产**：稳定复现坏行为的 checkpoint = 负例生成器候选（验收 = 新 prompt 上负行为
  复现率）；E-4 的"零救济"负结果在 G-4 变原料。→ MED-D 若 record 内/双标注对不够，此路可走。
  （出处：lessons G 收束批③④）

## 2. 训练工程（ms-swift 4.5.3 实效口径）

- **框架实际生效配置以运行时快照为准**：swift 替你做的默认决定（qwen3 非思考训练自动把 loss_scale
  升级为 `default+ignore_empty_think`）要么知道要么被坑——每个 run 核对 args.json，不靠文档与记忆。
  → MED-B 每 run 的验收步。（出处：lab-a2-run1.md §4-D1）
- **CLI 语法漂移用最小实验定**：4.x 无 `swift dpo`（走 `swift rlhf --rlhf_type dpo`）；List 参数空格
  分隔是唯一正解（transformers 5.x 的 hf_argparser 不解析 JSON 串）；子命令形态跨版本必搬家，开工前
  先读实际 help。→ HANDOFF MED-A 开工卡第 4 条已挂。（出处：tools/run_a2.sh 失败实录、check_dpo_g4.py）
- **对拍器必须复刻训练器的"实效管线"**：裸 `template.encode` 会显 4-token 掩码边界假红（新一代
  Qwen3 jinja 把空 think 放生成前缀侧）；带上训练同款 loss_scale 后文本+边界双绿。对拍器谱系
  （a2→b2→d1）是锚定先行的真实回报——新实验验证成本趋零。→ MED-B 前置 check_template_med（PLAN 已补）。
  （出处：lessons D 批①、项目阶段总结批④）
- **QLoRA 资源账两条曲线分开记**：显存 ≈ "4-bit 权重 + 常数"（激活被梯度检查点压平）；时长亚线性于
  参数。实测锚：14B QLoRA bs2×accum8 峰值 13.4GB / 478s@51 步；OOM 预案 = bs1×accum16。本仓序列
  <1K token，比姊妹域实验仓更宽裕。→ MED-B 机时预估的依据。（出处：lab-b/d-capacity*.md 显存表）
  - 2026-09-28 修正：上条"本仓序列 <1K token"实测不成立——F1 全 1154 行 **1096~1725 token**
    （14B tokenizer，MED-A 对拍前置实测），照抄 1024 会全量截断；**max_length 必用 2048**。
    教训入 lessons MED-A 批：序列长度必须 tokenizer 实测，字符直觉会错一个截断量级。
- **贴边 run 双查**：free MiB 够 ≠ 没人抢——本地 embedding 服务的 keep_alive 窗口会驻留，
  `kill` 不掉要走它自己的 stop API。GPU 预检 = free + compute-apps 进程表。→ HANDOFF §1 第 4 条；
  **2026-09-28 实测：兄弟项目委托跑占 10.5GB，开工必查**。（出处：lessons F 批③）
  - 2026-09-28 预检门阈值修正（MED-B OOM 实录）：**阈值 = 实测峰值需求 + 余量，不是乐观
    估计**——run_med_b.sh NEED 初版 11200 放行 free 11477，14B bs1@2048 首步 OOM（常驻外
    11.25GiB 差 42MiB），已修 12300（= 常驻外 ≥12GiB 红线量化）。历史锚（13.4GB@bs2）是
    1024 时代峰值，max_length 变 2048 后作废。贴边放行 = 把门卸了。（出处：lessons 快筛批③、
    output/med-b/14b-f1-oom-0928/）
- **LoRA 结构纪律**：r16/α32 是行为轴稳妥档；改 rank 必保 α/r=2.0（α 不跟 rank 是最隐蔽的第二变量，
  E-1"秩不敏感"假象的根源）；高秩对行为轴零增益甚至回退（defaults 配 r16 不配 r64）。
  → MED-B/D 起点配方的依据。（出处：lessons E-1b 批①、F 收束批地图条）
- **中文文本工程护栏**：字符类正则先枚举全/半角（`[^,，。；;]`）；删改类增强带"删后长度 ≥60% 源"
  断言；checkpoint 步数随数据集大小变，评测前 `ls` 取末步不写死。→ MED-C 造数与各波评测取点。
  （出处：tools/augment.py 开发实录、lessons E 批③④）
  - 2026-09-29 补条（MED-C 泄题防线实录）：**同源素材的近重复判据要收到"条目身份块"**——
    体裁骨架（字段名+正常体查套话+阴性检验模板）把全文相似度地板抬到 0.76-0.81（negn 十条
    同模板复写尤甚），全文 ratio 只配做粗筛；判据三层 = 主诉非逐字同 ∧ 全文 ratio<0.85 粗筛
    ∧ **叙事块（主诉+现病史）ratio<0.80 收紧**。起草者读过评测草稿就会无意识复写草稿句式
    （本波实测拦下近乎逐字的"本次为单位年度体检，平素体健…"），防线必须是机械判据不是自觉。
    （出处：tools/augment_med_c.py no_eval_leak、lessons MED-C 执行批①）
  - 2026-09-29 补条（MED-C 造数门）：**造数目标过判分器复判（评测器反向当 fidelity 门）**——
    fmt_ok/hit 语义轴用 score_item 直判，幻觉轴反向当"教学侧零编造"门（依据数值原子全在场），
    字段删除类增强的源依据按原子级过滤。判分单一事实源双向复用，门与卷天然同源不另造判据。
    （出处：tools/augment_med_c.py gate()/M2 过滤、lessons MED-C 执行批②）
  - 2026-09-28 末步选择实现陷阱（MED-B 执行批）：`ls | sort -t- -kN` 会被**路径内连字符**
    污染字段切分（`output/med-b/14b-f1/checkpoint-73` → epoch-1 静默当选）；用 `sort -V`
    （数值感知）+ "选中即校验"硬门（末步必为 219，非 219 拒跑）——选择器坏了大声失败。
    run_med_b4.sh 已固化此形态。另：跨轴复用解析器先查它的哨兵/归一化口径（轴⑥复用
    parse_diseases_tag 因哨兵过滤永假，gold 门抓出）。（出处：lessons 执行批①②）

- **【2026-09-30 · MED-D 批】共享卡上两型负载分开调度，NEED 门结构性防撞**：训练 =
  严格足迹（峰值贴预算，第三方上卡 250-610MiB 即穿）→ 走"等干净窗口 + 带清理重试"循环；
  推理 = 宽容足迹（4bit batch1 ~10GB，可容忍上卡者）→ 可先行铺开。两型并行时**低足迹型
  先跑、严格型挂门等**（门线 = 严格型需求线，评测占卡时门自动闭锁）——时序决策按
  "足迹严格度倒序"而非"依赖序正序"，整夜无碰撞。接力编排骨架：等待循环（free ≥ NEED）
  + 落地接力 watcher（上一级终态产物存在才启动下一级）+ 通知型等待器（人不在场时挂起
  回合）。幂等条件一律"终态产物存在"（末步 ckpt / score 文件），勿用"目录存在"。
  （出处：med-d run-all*.log、run_med_d3.sh、d3-s9-followup.log）

## 3. DPO 专项（第四杠杆）

- **剂量单位与 SFT 完全不同**：lr 5e-6（SFT 谱系 2e-4 的 1/40，swift 对 LoRA 默认 1e-4 更不可用）；
  **步数是开关型**（48 对×3 步已压满行为轴，9 步过校正），**β 不敏感**（三点扫描读数零形态差）——
  扫描先扫步数/epoch，β 默认即可。→ MED-D R7 网格的排序依据。（出处：lab-h-closeout.md §2）
- **对比损失的边际效用在负侧**：chosen 在 SFT 稳态下本已高概率（logps 起点分离）——偏好对的收益
  在"打压坏行为"，评估看负侧行为消退率而非正侧；不锚定生成质量，被推离稳态的形态包括格式劣化。
  → MED-D 读数口径 + 守门轴的由来。（出处：lessons G 收束批③）
- **行为泛化会吃契约行为**：偏好对教的"缺参→追问"会泛化到"看起来缺东西"的正常输入上，且专吃
  缺省带（OOD 上过校正加重 17%→50%）——DPO 配方交付必带"代价轴 + 适用域"两列，只能当单轴
  组合件不能当全轴终配。→ MED-D R7 守门条款。（出处：lessons H 第一批④、H 第二批③）
- **工程检查单**：数据格式 `messages + rejected_response` 对拍（空 think 块须落公共前缀，DPO 信号
  不被 think 差异污染）；`--ref_adapters` 同一 4bit base 挂冻结 ref（显存不翻倍，16GB 可行）。
  → MED-D 开工直接拷 check_dpo_g4.py 改路径。（出处：tools/check_dpo_g4.py、rlhf.py L178-191）

- **【2026-09-30 · MED-D 批】DPO 显存线要按拼批口径重定，探针先于数据改造**：micro-batch
  = chosen+rejected 拼批 [2, L]（L=两侧最长）——SFT 的需求线不平移（本仓实测：SFT 12300
  线下 DPO 首步即 OOM；cap1350 数据 + ml1360 配方峰值 12.39GiB，需求线 = 仅常驻服务
  12900）。定位长对 OOM 用**截断探针**（丢弃式 run 扫 max_length 阶梯，5 分钟出 seq 伸缩
  斜率）再定数据侧长度资格，勿直接重塑样本。另：adamw_bnb_8bit 的状态在首个
  optimizer.step 才物化——救稳态不救首步 backward 峰。
  （出处：reports/med-d-dpo.md §2、tools/profile_dpo_lengths.py）
- **【2026-09-30 · MED-D 批】adapters 模式 DPO 对契约层安全（与续训 SFT 分野）+ 负侧读数
  先量起点分离度**：MED-C 续训 SFT 出口词漂移 5/7 vs MED-D DPO 三臂出口违约 0/0 全保持
  ——对比损失调"同输入下链与链相对概率"，不动契约输出形态，**零覆盖条款门在 DPO 形态下
  自动豁免**。读"负侧消退率"前先量起点 logps 分离度（本例 -19.6 vs -55.5 = 负侧已压满），
  否则"负侧无变化"会被误读为 DPO 无效（边际收益在正侧证据质量）。
  （出处：reports/med-d-dpo.md §4 R8、tools/analyze_dpo_r8.py）
- **【2026-09-30 · MED-D 批】剂量开关型三域复现定案**：C-1 姊妹域实验仓（48 对×3 步）/ MED-C
  对症数据（12 条即中）/ MED-D 偏好对（3 步咬合、9 步≡3 步零过校正）——**最小有效剂量 +
  饱和即停可作跨域默认处方**；阶梯设计照抄 1/3/9，读数看 rewards 何时非零定位咬合步。
  （出处：reports/med-d-dpo.md §4 R7、M3.2-4）

## 4. 数据干预（第三杠杆）

- **数据动作两分法**：教"无冲突映射"（未言明→补默认）40 条 r16 即中；教"对抗性行为"（缺信号→
  不编造要追问）要先测**底座门槛**——零数据探针看自发行为，门槛之下数据被静默吃掉（同数据 1.7B
  0/7 / 14B 6/7）。造数前先给目标行为归类。→ MED-C 三臂的预期管理；MED-A R1 表正是门槛测量。
  （出处：lessons F 收束批②）
  - 2026-09-28 分层补条（MED-B 快筛实测）：**零样本"已会"要问是哪层——规则复读层的命中
    会被 SFT 抹掉**（garbled 20/20→0/20，识别在/契约出口错）。判读门槛表必须带能力层注
    （map M0.1 注），复读层"已会"对 SFT 设计的含义 = 必须补数据覆盖，不是白送；顺带：合成
    增强臂的预期从"保持+小档提升"改读"修复"。（出处：lessons 快筛批①、map M1-先行）
- **联合 SFT 轴间稀释**：两类教学信号在同类样本上梯度方向相反时，联合训练下行为类胜出（defaults
  被 clarify 吃掉一半）——合谱失败的正确下一步不是调配比，是换杠杆族或分轴 adapter。→ 若 MED-B/C
  多形态合料，必分轴验收。（出处：lessons G 第一批③）
- **覆盖计数的形态粒度**：最小单位不是"字段×单位"而是"字段×单位×**表述形态**"（纯数字/科学计数/
  分数/数词）——两次审计漏形态维度都导致对症数据白造。→ 本仓对应物：检验值的表述形态维度
  （MED-C 造数与审计时带上）。（出处：lessons H 第二批①）
- **同为"加正例"，与底座先验的距离决定疗效**：表述变体救不了分布问题（unit 臂零效 vs defaults
  即中）——加数据前先问"教的东西和已有分布冲突吗"。→ 本仓对应物：模型若对某病有强错误先验，
  加同病正例 vs 改分布表述的取舍。（出处：lessons E 批②）
- **【2026-09-29 · MED-C 批】零覆盖契约行为是"用进废退"资产**：system prompt 里显式承诺但
  训练语料零覆盖的行为（本例规则 4"无"出口），其字面粘性随训练量衰减——冠军之上续训 3ep
  （cg/cm 臂，分布仍零覆盖"无"）后出口词漂移为"健康/正常"（语义对、字面违约，cg 5/7 miss
  此形态）；分布内含该出口（cn 臂 36/12 条）即免疫且顺手修复边界漂移。**边界**：与"规则复读层
  被 SFT 抹掉"（M1-先行）方向一致但机制不同——那个是容量层复读被覆盖，这个是契约层零频衰减。
  → 落点：长训/续训交付前扫"零覆盖契约条款清单"（见 §5 补条）；已满分轴不需要分布内覆盖来
  "巩固"，巩固数据边际收益为负（cg/cm 对满分轴补数据反伤零覆盖条款）。
  （出处：reports/med-c-robust.md §5.2、map M2.2-1/4、lessons MED-C 判决批①）
- **【2026-09-29 · MED-C 批】加数据的代价轴两分法：稀释型 vs 范式型**：数据动作的伤害先问归属
  ——**稀释型**（挤占既有形态的份额，如覆盖 0.976→0.933）随配比下调可恢复（MED-C 12 条版
  恢复 0.958）；**范式型**（训练形态本身的代价，如续训叠加 epoch 的 ood 特化 0.133→0.050-0.083）
  与配比无关（12↔36 条 ood 0.067 逐位同）、配比不可修复，只能换训练形态或显式接受代价。
  **鉴别法 = 单变量配比重跑读"同轴同值"定案**——预注册写死"重跑一次不扫参"正是保住单变量性，
  鉴别价值优先于翻盘尝试。→ 落点：MED-D/E 读到"回退"先分类归属再选响应；配比处方只对
  稀释型有效。
  （出处：reports/med-c-robust.md §4 终判/§5.3-4、lessons MED-C 鉴别批①）
- **【2026-09-29 · MED-C 批】对症数据的最小有效剂量低于直觉**：边界语义（痊愈≠现患）教学
  12 条即清零漂移（20/20 超锚）、36 条已开始挤占覆盖形态——甜点区在"教学够用即可"，
  从低配比起（12 条 ≈ 1:96）按需上调。→ 落点：MED-D 偏好对剂量同理（C-1"步数开关型"

## 5. 判读纪律（读数层）

- **读数分轴**：训练 loss↓ / 解题↑ / 行为持平可以同 run 并存——"X 有没有用"先改写成"X 对哪条轴
  有没有用"。→ 本仓四轴（疾病 F1/格式/依据/鲁棒）× seen/unseen 两层，全部预注册分轴判据。
  （出处：lessons 项目阶段总结批⑦）
- **loss 口径三则**：ep1 loss 度量底座先验不度量容量（跨底座比 loss 只在收敛后）；epoch 边界尖峰
  会抬高均值（先拆口径再读数，本仓沿用"含尖峰"口径）；预注册预测要预估尖峰权重。
  → MED-B 的 loss 读数规程。（出处：lessons B 批②、D 批③）
- **跨容量"逐位同错"是数据构成指纹**（适用条件：超参族全同）：错误值全等即定案数据构成问题；
  但换秩/缩放/模板任一隐性超参后"全等"失效——跨实验引用前先核对。→ 若五档模型在某病历上
  同错同值，即数据/先验问题的判据。（出处：lessons B 批①、E-1b 批②）
- **两级快筛的产出是"槽级读数"**：1.7B 先跑不是省机时，是容量敏感探针——哪个亚型翻/翻一半/回潮
  分别标记数据可教/容量门槛/样本间不稳。→ MED-B 的 1.7B→14B 两级设计读法。（出处：lessons G 第二批②）
  - 2026-09-28 阶梯读法补条（MED-A 后提炼）：**容量阶梯是一次性测量投资**——读数先问归属层
    （脚手架/知识容量/模式识别等，全表 map M0.1），再问 headroom（单调未饱和=有空间）；
    阶梯给数据动作定价（门槛下静默吃掉，见 §4 两分法）并提供"逐位同错"指纹判据的使用前提
    （≥2 档同超参族）。**阶梯答"门槛在哪"不答"配方孰优"**——零训练阶梯定价后微调砍到两端
    （探针档+交付档），中间档不训（无独占行为层=重复信息）。→ 本仓落点：map.md M0 即此读法
    产物；MED-B 两级设计的依据。（出处：lessons 容量阶梯方法论批、MED-A 报告 §4）
- **错误信息会说谎**：工具报错有 fallback 链时，报错文本不能直接当归因依据，回原始输入对质。
  → MED-A 评测器开发期的调试纪律。（出处：lessons H 第一批②）
- **改善标层归因 + 适用域**：效果叙事分列"模型本体/数据/偏好/脚手架"层；判决回填带适用条件/失效
  条件列（后续判决落在同域时先条件化前判决）。→ MED-E 地图 v1 的表结构已按此设计（读数/代价轴/
  适用域/归属层四列）。（出处：lessons H 收束批②③）
- **【2026-09-29 · MED-C 补条】零覆盖契约条款清单 = 长训/续训交付必过门**：交付前对
  system prompt 全部非主行为条款（本仓 = 规则 4"无"/规则 5"数据异常"/规则 7"缺少关键
  诊断信息"三出口）逐条查训练分布覆盖：有覆盖 → 读数防回退即可；零覆盖 → 要么补分布内
  样本、要么在交付注记里声明粘性衰减风险。读数时"语义对、字面违约"形态单列计数

## 7. 项目级方法论（2026-09-30 · med-diag-lab 收官总回收）

> 六波收官后的一次性总回收：**跨波才可见**的形态规律，单波 lessons 装不下。性质同全册
> ——纪律迁移、结论不迁移，本仓数字仅作证据引用。

- **项目骨架 = 测量先行 + 杠杆穷举 + 收官判据前置**：零训练基线（五档阶梯）先给全部数据
  动作定价（门槛/headroom/归属层），训练波只在交付档展开、每波一个杠杆族（数据形态 →
  合成增强 → 偏好 → 收官读数）；**"什么时候停"与"做什么"同等预注册**（D-08 三账合算：
  信号残量 / 杠杆完成度 / 边际收益 flatten）——六波无一波因"感觉做完了"收，也无一波因
  "还能再试"续；增件超预算走显式拍板（MED-E bf16 列），不沉默砍也不硬跑。
  → 新域项目立项时把收官判据写进 PLAN，同时防 scope creep 与无限续命。
  （出处：PLAN D-08/D-09、med-e 报告 §2 拍板实录）
- **迭代的载体是数据与配方，不是 checkpoint——叠加只在目标切换时成立**：同目标往冠军上
  加数据 = 范式型代价（MED-C 续训 ood 腰斩且配比不可修复，R5'）；换目标叠加 = 零代价
  （MED-D adapters DPO 挂 SFT 冠军，契约层免疫，R7/R8）。两波对照钉死分界律：**管线式
  叠加（SFT→DPO）合法，"SFT→更多数据 SFT"应回底座重演**；数据量大时重训常优于续训
  （二期预案已把"续训 vs 重训两形态对照"写成条款）。终态交付形态由此定型：**主配方 +
  分轴组件 + 组装查询表**（map M4），不是单体滚雪球。（出处：M2.3/M3.3 对照、
  research/2026-09-30-post-medd-continue-plan.md §5）
- **SFT→DPO 顺序不可倒：模仿建立分布，对比只在分布内排序**：DPO 的信号是"同输入下
  chosen 压过 rejected"，教不了分布外的新行为——先 DPO 底座 = 把最贵的偏好信号花在教
  最便宜的格式上，且弱策略上做偏好压制易推向 chosen 表面句式。读数前提同样依赖顺序：
  起点分离度（本例 chosen -19.6 vs rejected -55.5 = 负侧已压满，边际收益定位正侧证据
  质量）只在 SFT 后有意义——与 InstructGPT 谱系（SFT→RM→PPO）同构，DPO 砍掉奖励
  模型没砍掉顺序。（出处：med-d 报告 §4 R8、M3.2-1/3）
- **评测器是口径资产，单一事实源设计的复利**：判分 v1.1 冻结跨波可比只是起点——同一个
  score_item 在仓内复用四次：gold 自校准门（改口径必过）、造数 fidelity 门（评测器反向
  判造数）、离线重判/分层读数（stratify 同 normalize 口径）、出口形态扫描（契约条款）。
  评测器先行 = 后续每波验证成本趋零。**新项目第一件要写的不是训练脚本，是评测器 +
  gold 门**。（出处：tools/run_eval_med.py 全谱系调用点、augment_med_c gate()）
- **同型预注册错判的元规则**（§1 预注册条目族的收官补）：本仓三次同型错判（格式冷启动
  R1-②、garbled 全档满分 R1-④、无病探针 30/30）全为同一形状——**低估"显式契约 +
  示例"行为的零样本能力**。规则：预注册押"底座不会 X"且 X 是契约显式行为时，先花最
  便宜的零样本探针再写判决；**同型错判第二次出现即升设计层默认**（本仓第三次才立规，
  前两次本可免）。台账按"形状"归档，不按波次。（出处：map M0.4 台账 + M1 补行）
